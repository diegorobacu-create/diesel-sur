# Diesel Sur

Sitio institucional estatico creado con WebStudio Pro. HTML y CSS sin dependencias ni paso de compilacion.

## Ejecutar

Abrir `index.html` en un navegador o servir esta carpeta con un servidor de archivos estaticos.

## Contenido y contacto

Instagram proporcionado por el usuario: https://www.instagram.com/dieselsur_/

Los botones abren ese perfil. La biografia y las publicaciones no pudieron consultarse de forma automatizada; la estetica es una propuesta provisional, no una reproduccion verificada del perfil.

La localidad mostrada procede de referencias publicas anteriores y debe reconfirmarse antes de un lanzamiento comercial. No se publican telefonos, correos, horarios ni certificaciones sin confirmar.

No hay formulario ni servidor; el sitio no almacena consultas.

## Archivos publicados

- `index.html`: contenido y navegacion.
- `styles.css`: diseno y adaptacion movil.
- `README.md`: ejecucion y limites del contenido.

El antiguo `app.js` es un residuo del formulario descartado. No se carga desde el HTML y se excluye de la publicacion, que no requiere JavaScript.

## Publicacion

Repositorio: https://github.com/diegorobacu-create/diesel-sur

Subir archivos al repositorio no habilita automaticamente GitHub Pages. Para alojarlo alli: Settings > Pages > Deploy from a branch > main > / (root).

## Validacion

Revision estatica de enlaces, referencias locales, estructura y ausencia de secretos en los archivos publicados. La revision visual quedo pendiente porque el control del navegador local esta desactivado. No se afirma conformidad WCAG completa ni se presentan metricas de rendimiento sin medicion.
